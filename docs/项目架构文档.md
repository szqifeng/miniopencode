## 🔑 核心模块

### 1. 服务器层 (`src/server/`)

#### MiniOpenCodeServer
- **职责**：Express 服务器封装，模块注册机制
- **端口**：默认 3000（可通过 `PORT` 环境变量配置）
- **功能**：
  - 插件式模块注册 (`register(name, module)`)
  - 中间件配置（JSON 解析、错误处理）
  - 健康检查端点 (`/health`)

```typescript
// 使用示例
const server = new MiniOpenCodeServer();
server.register('api', apiModule);
await server.start();
```

### 2. Agent 层 (`src/agent/`)

#### Agent 控制层 (`index.ts`)
- **职责**：编排工具，调用 Process 执行 React Loop
- **核心接口**：
  - `createAgent(tools?)`：创建 Agent 实例
  - `run(params)`：非流式执行
  - `runWithStream(params)`：流式执行（SSE）
  - `withTools(toolSet)`：动态添加工具
  - `withToolsById(toolIds)`：按 ID 选择工具

#### API 路由 (`api.ts`)
- **职责**：接收 HTTP 请求，调用 Agent 处理
- **端点**：
  | 端点 | 方法 | 功能 |
  |------|------|------|
  | `/api/web/chat/stream` | POST | 流式对话（支持工具调用） |
  | `/api/web/chat/session/:sessionId` | GET | 获取会话详情 |
  | `/api/web/chat/session/:sessionId` | DELETE | 删除会话 |
  | `/api/web/sessions` | GET | 获取会话列表 |

#### React Loop 执行器 (`process.ts`)
- **职责**：执行多轮 React Loop（最多 5 轮）
- **核心方法**：
  - `processTask()`：非流式处理
  - `processTaskWithStream()`：流式处理，支持 SSE 事件推送

#### LLM 交互层 (`llm.ts`)
- **职责**：与 MiniMax AI 交互
- **配置**：
  - Provider: Anthropic (通过 MiniMax 接口)
  - 模型: `MiniMax-M2.7-highspeed`
  - 最大输出: 8192 tokens

#### 会话管理 (`session.ts`)
- **职责**：管理多轮对话的会话上下文
- **核心方法**：
  - `getSession(id)`：获取或创建会话
  - `addMessage(sid, msg)`：添加消息
  - `getMessages(sid)`：获取消息列表
  - `clearSession(sid)`：清除会话
  - `updateSessionTitle(sid, title)`：更新标题

### 3. 工具层 (`src/services/toolService.ts`)

#### 内置工具

| 工具 ID | 功能 | 参数 |
|---------|------|------|
| `read` | 读取文件内容 | `path: string` |
| `write` | 写入内容到文件 | `path: string, content: string` |
| `edit` | 编辑文件（字符串替换） | `path, oldString, newString` |
| `grep` | 在文件中搜索内容 | `pattern, path?, include?` |
| `bash` | 执行 bash 命令 | `command: string, cwd?` |
| `webfetch` | 获取 URL 内容 | `url: string, format?` |

### 4. 中间件 (`src/middleware/`)

#### 认证中间件 (`auth.ts`)
- **职责**：验证 `X-API-Key` 请求头
- **配置**：`API_KEY` 环境变量

## 🔄 核心工作流程

### 流式对话流程

```
1. 用户请求 → POST /api/web/chat/stream
2. 认证中间件 → 验证 X-API-Key
3. API 路由 → 解析消息和 sessionId
4. 会话管理 → 保存用户消息到会话
5. Agent 创建 → 调用 createAgent()
6. React Loop 执行 → 最多 5 轮循环
   ├─ LLM 调用 → 生成回复和工具调用
   ├─ 工具执行 → 调用具体工具
   ├─ 结果反馈 → 将工具结果传回 LLM
   └─ 继续循环 → 直到无工具调用
7. SSE 流式推送 → 实时返回所有事件
8. 消息保存 → 保存 assistant 消息到会话
```

### React Loop 多轮执行机制

```
Loop 0:
  - LLM 接收用户消息
  - 生成回复 + 工具调用
  - 执行工具
  - 累积消息: [user, assistant, user(工具结果)]

Loop 1:
  - LLM 接收完整历史
  - 基于工具结果继续推理
  - 可能继续调用工具或结束
  
... (最多 5 轮)

终止条件:
  - finishReason !== 'tool-calls'
  - 达到最大循环次数 (maxLoops=5)
```

## 📡 SSE 事件类型

后端流式返回的事件类型（`src/agent/types.ts`）：

```typescript
type SSEEventType = 
  | 'text'              // 文本内容
  | 'text-delta'        // 文本增量
  | 'text-start'        // 文本开始
  | 'text-end'          // 文本结束
  | 'tool-call'         // 工具调用
  | 'tool-result'       // 工具结果
  | 'tool-input-delta'  // 工具输入增量
  | 'tool-input-start'  // 工具输入开始
  | 'tool-input-end'   // 工具输入结束
  | 'reasoning'        // 推理内容
  | 'reasoning-delta'  // 推理增量
  | 'reasoning-start'  // 推理开始
  | 'reasoning-end'    // 推理结束
  | 'start'            // 开始
  | 'start-step'       // 步骤开始
  | 'finish-step'      // 步骤完成
  | 'finish'           // 完成
  | 'error';           // 错误
```

## ⚙️ 配置

### 环境变量 (`.env`)

```bash
API_KEY=om_fixed_api_key_12345          # API 认证密钥
MINIMAX_CN_API_KEY=your_minimax_api_key # MiniMax AI 密钥
STORAGE_TYPE=file                       # 存储类型
PORT=3000                              # 服务端口
```

### 系统提示词 (`prompts/`)

#### default.md
- 角色定位：专业的 AI 助手
- 能力说明：回答问题、编写代码、文件操作、命令执行、内容搜索
- 使用规则：优先使用工具、markdown 格式、简洁明了

#### title.md
- 任务：生成简短的会话标题（≤50字符）
- 规则：与用户消息同语言，自然语法、不包含工具名

## 🛡️ 安全机制

1. **API 认证**：所有 `/api/*` 接口需要 `X-API-Key` 请求头
2. **工具调用白名单**：只允许使用内置工具
3. **文件操作限制**：路径由用户指定，无额外限制（可扩展）
4. **命令执行控制**：通过 bash 工具执行，有超时机制
5. **请求超时**：HTTP 请求 30 秒超时

## 📊 数据结构

### Session（会话）

```typescript
interface Session {
  id: string;              // 会话 ID
  title?: string;          // 会话标题
  messages: Message[];     // 消息列表
  createdAt: number;       // 创建时间戳
  updatedAt: number;       // 更新时间戳
}
```

### Message（消息）

```typescript
interface Message {
  role: 'user' | 'assistant' | 'system';
  id: string;
  parts: Part[];           // 多部分内容
  createdAt: number;
}
```

### Part（消息片段）

```typescript
type Part = 
  | TextPart              // 文本
  | ToolCallPart          // 工具调用
  | ToolResultPart        // 工具结果
  | ReasoningPart         // 推理内容
  | FinishStepPart        // 步骤完成
  | ErrorPart;            // 错误
```

## 🚀 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 配置环境变量
```bash
cp .env.example .env
# 编辑 .env 填入 API_KEY 和 MINIMAX_CN_API_KEY
```

### 3. 启动服务
```bash
# 开发模式（监听文件变化）
npm run dev

# 生产模式
npm start
```

### 4. 调用 API
```bash
curl -X POST http://localhost:3000/api/web/chat/stream \
  -H "Content-Type: application/json" \
  -H "X-API-Key: om_fixed_api_key_12345" \
  -d '{
    "messages": [{"role": "user", "content": "你好"}],
    "useTools": true
  }'
```

## 📝 开发指南

### 添加新工具

1. 在 `toolService.ts` 中定义工具：
```typescript
const newTool = {
  id: 'newTool',
  description: '工具描述',
  inputSchema: jsonSchema({ ... }),
  async execute(args) { ... }
};
```

2. 注册到 TOOLS 对象：
```typescript
export const TOOLS: ToolSet = {
  // ...existing tools
  newTool: newTool
};
```

### 添加新 API 端点

1. 在 `api.ts` 中添加路由：
```typescript
router.get('/new-endpoint', async (req, res) => {
  // 处理逻辑
});
```

2. 确保路由在 `setupApi` 函数中被注册

### 添加新中间件

1. 创建中间件文件（如 `src/middleware/newMiddleware.ts`）
2. 在 `MiniOpenCodeServer.ts` 中注册：
```typescript
this.app.use(newMiddleware);
```
